메시징/비동기 숙련도 향상 실습 계획

대상 영역: @Async, Kafka, RabbitMQ, Spring Batch / Quartz 목적: 포트폴리오에 바로 넣기 전, 각 기능을 손에 익도록 반복 연습

원칙
하나의 큰 프로젝트가 아니라, 개념 하나만 다루는 아주 작은 실습을 여러 개로 쪼갠다.
실습 하나는 반나절~하루 안에 끝낼 수 있는 크기로 제한한다. 안 끝나면 범위를 더 줄인다.
같은 패턴을 도메인만 바꿔서 2~3회 재구현한다. 코드를 안 보고 얼마나 빨리 다시 만드는지가 숙련도의 척도다.
포트폴리오 반영은 맨 마지막 단계에서, 여기서 잘 됐던 조합만 골라 하나의 시나리오로 통합한다.
